Calibration controls

Each contact uses completed residuals only. A wider interval may cover more observations but loses sharpness. Separate calibration by horizon avoids treating distant forecasts like one-step predictions.

Interval score = width + 2/α × distance beyond the nearest bound for missed targets (α = 1 − target coverage). This discourages both exaggerated certainty and unnecessarily wide intervals. Results are illustrative until independently tested.

Immutable observations and issued forecast ledger

Original observations are never replaced. Every issuance records origin, target, interval, evidence count, and calibration settings. A pending prediction is resolved once, when its target arrives. JSON exports include the full session ledger; this is not a cryptographically authenticated archive.
