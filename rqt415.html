The Odd Denominator Bridge

Every reduced rational solution v=w/d to q(v)=-1 has odd denominator d, and numerator parity 001, 011, or 110. This is a global necessary theorem from the actual Gram matrix.

Exact result

If d is even, q(w)=-d² is 0 mod4; the full Gram's parity table forces all coordinates of w even, contradicting lowest terms.

Numerator classes: 24 solutions modulo 4, 96 modulo 8. These are modular classes, not integer root witnesses. Root19 OPEN.
