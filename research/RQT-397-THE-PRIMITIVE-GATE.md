# RQT-397 — The Primitive Root Gate

Date: 2026-11-15. Parent: RQT-396. Fixed reduced basis: RQT-388.

## New global invariant

If the integral vector r = B(x,y,z) has F4-norm -2 and
d = gcd(|x|,|y|,|z|) > 1, then r = d*w for an integer vector w
and -2 = d² (wᵀ Q w). Since d² cannot divide 2 for any d > 1,
**every norm-minus-two solution is primitive**.

This is a valid infinite-size restriction. It does not, by itself,
eliminate RQT-396 local survivors.

## New computable test

For a prime p and exponent k, enumerate the vectors modulo p^k
satisfying vᵀQv ≡ -2 (mod p^k). Lift survivors from p^(k-1) to p^k by
testing their p³ coordinatewise lifts. This never divides by a
coefficient that might be noninvertible modulo p.

At k>=2, residue vectors with every coordinate divisible by p must
be absent: their norm is 0 modulo p², whereas -2 is not 0 modulo p².

If an entire level is empty, the frozen lattice contains no exact
root19 at any coordinate size. A positive level is ONLY local
feasibility, not integral existence. A singular local branch might
die at a higher prime power, so deeper tests remain meaningful.
