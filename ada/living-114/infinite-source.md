# ADA-114C — Infinite source and visible shadow

.dlw

Canonical user notation (verbatim):

```text
source : inf-+inf
shadow : (inf) - + [inf}
vector : [ {n}^{n} (s) {n}^{n} ]
```

The shadow is the visible source and lynchpin. Preserve delimiter asymmetry, including the intentionally unmatched `[inf}`. Do not automatically normalize. The semantics of individual boundary operators and a formal projection remain to be specified; infinite notation is architectural, not a demonstrated infinite computational capacity.
