Portable witness envelope

The portable frame contains one terminal bit plus seven witness segments of lengths 64, 32, 16, 8, 4, 2 and 1. It can rebuild the original input without storing a second copy of the source.

Security boundary: recoverability is not authentication. Someone who changes the terminal bit and witness can generate a different valid source. Use the QG-013 AES-GCM envelope to authenticate and protect this frame before sending it.

This is a computational Chrome Dot metaphor. No physical quantum compression or new physics is asserted.
