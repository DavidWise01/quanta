# Editorial Charter · QUANTA

1. **Spark first.** Write a story a curious adult can follow. Every new term starts with an image or scene.
2. **Math stays visual.** Use compact symbols such as `0`, `.`, `{{i}}`, `[ ]`, and `( )` in the main text; move dense proofs into optional technical notes.
3. **One new idea per page when possible.** Explain before layering.
4. **Every chapter has a puzzle.** Readers predict something before seeing the answer.
5. **Observe, don't decree.** Separate language definitions, mathematical consequences, simulation results, and physical hypotheses.
6. **Preserve provenance.** Keep dated changes and avoid rewriting historical definitions silently.
7. **Accessible by default.** High contrast, responsive design, keyboard-accessible interactions, and textual descriptions of diagrams.
8. **Publication source.** Markdown chapters are the canonical prose; GitHub Pages is the interactive companion; EPUB/print will be built from reviewed manuscripts.
9. **No fabricated canon.** If an older kernel's exact dimensions or syntax have not been verified, label them open for reconciliation.
