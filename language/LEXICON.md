# QUANTA · Visual Lexicon

Each symbol has a **reader's intuition** and a **formal status**. Until canonical definitions are confirmed, illustrations below are provisional.

| Symbol | Reader sees | Language status |
|---|---|---|
| `0` | Begin here | Structured origin concept; exact kernel schema pending |
| `.` | One here | Position marker; Q1 adds identity tracking when claiming persistence |
| `|` | An edge or separation | Boundary marker; Q3 requires a rule for passage and retention |
| `[ ]` | A place held between sides | Box / retention metaphor; Q4 preserves container/content distinction |
| `( )` | A path that returns | Proposed loop / toroidal token; not sufficient to assert motion, and not literally a torus |
| `{ }` | Room for change | Generative / transformation scope metaphor |
| `}{` | Opening a division | Provisional unbinding notation |
| `{{i}}` | A recognizable center | Proposed identity/observer token |
| `/\\` | A fold or diamond | Reserved geometry metaphor |

| `[ [ . ] ]` | A marked point inside a box inside a box | Provisional nested containment reading |
| `[()]` | A loop held inside a box | Core visual metaphor for a working gap, not an established physical geometry |

| `.|.|.|.|.` | Five dots and four separators; five-station path in Chapter 8's teaching example | Example relay interpretation only; general transport grammar remains reserved |

## Use in the book

First show the mark; then give one sentence; then show one visual relation; finally provide optional formal detail.

Do not assert that the shape of a symbol proves the shape of a particle, or that a number represents a physical dimension without a testable definition.
