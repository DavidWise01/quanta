The Downward Spiral

The language arranges the route. Eight-address globules follow a clockwise outer-to-inner spiral. Each globule folds toward one Chrome Dot. The message is reordered through that address path, then encrypted locally using Web Crypto's AES-256-GCM.

AES-256-GCM authenticates the header and ciphertext; PBKDF2-HMAC-SHA-256 derives a key from your password. The transport permutation is not the cipher. The current prototype is not independently security-audited.

One route, reversible

Across dimensions 3 to 11, every address is visited exactly once. At 11D, 2,048 addresses form 256 globules of eight, laid out across a 16×16 clockwise inward spiral. The transport route preserves order reversibly; the Chrome Dot preserves lineage.

Physical boundary

Superstring and M-theory dimension counts are not evidence that this computer routing system physically occupies eleven dimensions. Here the dimensions label abstract hypercube coordinates, and the word “globule” names a group of eight.
