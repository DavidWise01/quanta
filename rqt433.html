The First-Seed Obstruction Gate

Two global modular obstructions exclude infinite families of fixed Pell seeds from the original candidate-successor lattice.

     RQT-433 : FIRST-SEED OBSTRUCTION

    | q(x,y,z)+d²=0                 |
    |             |                   |
    |       y = 5*x (mod p)          |
    |          /        \\             |
    |        p=13       p=23         |
    |      d²=11x²    d²=7x²        |
    |      NONSQUARE  NONSQUARE     |
    |          \\        /             |
    |      NO FIXED SEED             |
    | 9802/89401 xy classes gone     |
    |             |                   |
    |         ROOT19 OPEN            |

p=13: y=5x forces d²=11x² mod13, impossible for x nonzero modulo13.
p=23: y=5x forces d²=7x² mod23, impossible for x nonzero modulo23.

9802 of 89401 xy residue classes modulo299 are excluded, independent of z,d magnitude. Even real-cone examples (41,23) and (140,79) are eliminated.

Root 19 is still OPEN; this is not a global no-root proof.
