# QG-027 — SEE / DO / LEARN semantic alphabet

**Carrier:** `||||`. Each letter receives exactly three authored, same-initial terms.

- **SEE:** a cue to observe.
- **DO:** an action or behavioral verb.
- **LEARN:** a result, interpretation or learning target.

Examples: `||A|| = {see: Alarm, do: Action, learn: Achieve}`; `||Q|| = {Question, Query, Qualify}`.

Across all A–Z, there are **26 × 3 = 78 semantic role assignments**, preserved exactly by the deterministic vocabulary module. These are proposed labels, not self-evident linguistic meanings, measurements or autonomous learning. Notably, X uses coined/hyphenated X-prefixed role labels (X-ray, X-ray-test, X-reference).

This layer assigns words to the existing canonical QG-026 glyph token; it does not change the 60-station geometry. The next compositional boundary would bind SEE/DO/LEARN role transitions to the current A–Z glyph's ring positions and stroke verbs.
